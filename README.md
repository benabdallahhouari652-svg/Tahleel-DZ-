# 🎯 تحليل DZ (Tahleel DZ)

> منصة تحليل الفيديو الرياضي الاحترافية الجزائرية والعالمية — مستوحاة من **Dartfish** · **LiveTag Pro** · **Once Sport**

---

## 🚀 كيفية التشغيل

```bash

start index.html
```

لا يحتاج إلى تثبيت أو سيرفر — يعمل مباشرة في المتصفح.

| الميزة | الوصف |
|--------|-------|

| 🎨 **حزمة الرسم التلفزيوني (TV Telestration)** | عدسة تكبير VAR 2.5x، خط تسلل 3D وجدار افتراضي، مساحة حرة، قوس تمرير هوائي، شارة لاعب ذكية، كشاف إضاءة، حلقة 3D، وقياس مسافات |
| 🏷️ **نظام التاغينغ** | وسم الأحداث في الوقت الفعلي، اختصارات لوحة المفاتيح |
| 📋 **الجدول الزمني** | عرض بصري للتاغات ومحدد نطاق اللقطة التفاعلي القابل للسحب |
| ⚽ **اللوحة التكتيكية والتدريبية (v2.0)** | ملاعب كاملة ونصف ملعب، 9 معدات تدريبية متطورة (مخاريط، حواجز، دمى، سلالم، مرمى صغير، أعمدة، حلقات)، أسهم منحنية ومسارات مراوغة متعرجة، مكتبة خطط محلية، تمارين جاهزة، وتصدير صور HD و JSON و PDF |
| 📄 **تقرير المباراة الفني الرسمي (PDF Generator v2.2)** | توليد تقرير فني شامل متعدد الصفحات للطباعة و PDF (غلاف رسمي، إحصائيات، مخطط رادار، لقطة اللوحة التكتيكية، جدول اللقطات الفنية المقصوصة، وتوقيع الطاقم الفني) |
| 📊 **التقارير والإحصائيات** | مؤشرات أداء KPI، رسوم بيانية (Bar, Pie, Radar)، تصدير CSV |
| 🆚 **مقارنة الفيديو** | تشغيل متزامن لفيديوهين مع إزاحة زمنية |
| 🌙 **ثيم مزدوج** | Dark/Light mode |
| 📱 **متجاوب** | يعمل على Desktop, Tablet, Mobile |

## 🎮 اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---------|---------|
| `Space` | تشغيل/إيقاف الفيديو |
| `I` | تحديد نقطة بداية اللقطة [In] |
| `O` | تحديد نقطة نهاية اللقطة [Out] |
| `,` أو `<` | إطار للخلف -1 Frame (0.04s) |
| `.` أو `>` | إطار للأمام +1 Frame (0.04s) |
| `L` | تفعيل / إيقاف تكرار اللقطة (Loop Selection) |
| `Ctrl+Z` / `Ctrl+Y` | تراجع / إعادة في الرسم |
| `Alt+1..6` | التنقل بين الشاشات |
| `A` | تاغ هجمة (كرة القدم) |
| `G` | تاغ هدف |
| `D` | تاغ دفاع |
| `F` | تاغ خطأ |
| `R` | تاغ ركنية |
| `K` | تاغ ركلة حرة |
