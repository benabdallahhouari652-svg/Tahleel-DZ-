# 🎯 تحليل DZ (Tahleel DZ)

> منصة تحليل الفيديو الرياضي الاحترافية الجزائرية والعالمية — مستوحاة من **Dartfish** · **LiveTag Pro** · **Once Sport**

---

## 🚀 كيفية التشغيل

```bash
# فتح التطبيق مباشرة في المتصفح
start index.html
```

لا يحتاج إلى تثبيت أو سيرفر — يعمل مباشرة في المتصفح.

---

## ✨ المميزات

| الميزة | الوصف |
|--------|-------|
| 📹 **محلل الفيديو** | تشغيل بسرعات مختلفة (0.25x → 4x)، Frame-by-frame |
| 🏷️ **نظام التاغينغ** | وسم الأحداث في الوقت الفعلي، اختصارات لوحة المفاتيح |
| 🎨 **أدوات الرسم** | سهم، دائرة، مستطيل، رسم حر، نص على الفيديو |
| 📋 **الجدول الزمني** | عرض بصري للتاغات على خط زمني متعدد المسارات |
| ⚽ **اللوحة التكتيكية والتدريبية (v2.0)** | ملاعب كاملة ونصف ملعب، 9 معدات تدريبية متطورة (مخاريط، حواجز، دمى، سلالم، مرمى صغير، أعمدة، حلقات)، أسهم منحنية ومسارات مراوغة متعرجة، مكتبة خطط محلية، تمارين جاهزة، وتصدير صور HD و JSON و PDF |
| 📊 **التقارير** | إحصائيات، رسوم بيانية (Bar, Pie, Radar)، تصدير CSV |
| 🆚 **مقارنة الفيديو** | تشغيل متزامن لفيديوهين مع إزاحة زمنية |
| 🌙 **ثيم مزدوج** | Dark/Light mode |
| 📱 **متجاوب** | يعمل على Desktop, Tablet, Mobile |

## 🎮 اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---------|---------|
| `Space` | تشغيل/إيقاف الفيديو |
| `Alt+1..6` | التنقل بين الشاشات |
| `A` | تاغ هجمة (كرة القدم) |
| `G` | تاغ هدف |
| `D` | تاغ دفاع |
| `F` | تاغ خطأ |
| `R` | تاغ ركنية |
| `K` | تاغ ركلة حرة |

## 🏟️ الرياضات المدعومة

- ⚽ كرة القدم (Soccer)
- 🏀 كرة السلة (Basketball)
- 🤾 كرة اليد (Handball)
- 🏐 كرة الطائرة (Volleyball)
- 🏉 الرغبي (Rugby)
